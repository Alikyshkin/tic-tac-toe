# Крестики-нолики

Браузерная игра для двоих за одним экраном или партии против компьютера. Соберите три знака в ряд по горизонтали, вертикали или диагонали. Если поле заполнено и линии нет, будет ничья.

## Запуск

Откройте `index.html` в браузере. Установка и сервер не нужны.

Выберите соперника и нажмите на свободную клетку. Можно пользоваться мышью, сенсорным экраном или клавишами Tab, Enter и пробел. Кнопка «Заново» начинает партию в выбранном режиме.

Игра написана на HTML, CSS и JavaScript. Компьютер сначала ищет выигрышный ход, затем блокирует угрозу и выбирает свободную клетку.
